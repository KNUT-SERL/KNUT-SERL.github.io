# SER Lab 홈페이지 관리 설명서

이 문서 하나로 홈페이지의 **모든 수정 가능한 부분**을 관리할 수 있습니다.
코딩 지식은 필요 없습니다. 파일을 올리거나, 텍스트 파일의 값을 고치면 됩니다.

> **모든 수정의 공통 순서**
> 1. GitHub 저장소에서 해당 폴더/파일로 이동
> 2. 파일 수정: 파일 클릭 → 연필 아이콘(Edit) → 고치기 → **Commit changes**
>    파일 업로드: 폴더로 들어가서 → **Add file → Upload files** → 끌어다 놓기 → **Commit changes**
> 3. 1~2분 뒤 사이트에 반영. 안 보이면 `Ctrl+F5` (Mac: `Cmd+Shift+R`) 강력 새로고침

## 1. 구성원 관리 — `members/` 폴더

**구성원 한 명 = 파일 두 개** (프로필 `.txt` + 사진 `.png`/`.jpg`).
`members/` 폴더에 올리기만 하면 사이트가 자동으로 인식해 카드를 만듭니다.
목록 파일을 따로 고칠 필요가 **없습니다**.

### 1-1. 파일 이름 규칙: `접두사-순번-영문이름`

```
MS-001-JunwonJang.txt     ← 프로필 (석사 1번, 장준원)
MS-001-JunwonJang.png     ← 사진 (같은 이름, .jpg 도 가능)
```

| 접두사 | 뜻 | 표시되는 페이지 |
|---|---|---|
| `PHD` | 박사후연구원(포닥) | Ph.D. Course |
| `DR` | 박사과정 | Ph.D. Course |
| `DRMS` | 석박사 연계과정 | Ph.D. Course |
| `MS` | 석사과정 | M.S. Course |
| `MSBS` | 학석사 연계과정 | M.S. Course |
| `BS` | 학사과정 | Undergraduate |
| `INT` | 인턴 | Undergraduate |
| `ALU` | 졸업생 | Alumni |

- **페이지 안 표시 순서**: 접두사 순(위 표의 순서) → 같은 접두사 안에서는 순번(001, 002, …) 순.
  구분선 없이 한 목록으로 이어집니다
  - Ph.D. Course: 포닥 → 박사과정 → 석박사 연계 / M.S. Course: 석사 → 학석사 연계 / Undergraduate: 학사 → 인턴
- **졸업생(`ALU`)의 순번 = 졸업 순서**입니다 (001이 첫 졸업생)
- 순번은 접두사마다 따로 셉니다 (MS-001과 BS-001은 서로 다른 사람)
- 영문이름은 이름+성을 붙여 씁니다: Junwon Jang → `JunwonJang`

### 1-2. 구성원 추가하기

1. `members/` 폴더에서 기존 `.txt` 파일 아무거나 열어 내용을 복사
2. **Add file → Create new file** → 파일 이름을 규칙대로 입력 (예: `MS-006-GildongHong.txt`)
3. 붙여넣고 내용만 바꿔서 **Commit changes**
4. 사진이 있으면 같은 이름으로 업로드 (예: `MS-006-GildongHong.png` 또는 `.jpg`)
   - **사진이 없어도 됩니다** — 1~2분 안에 파스텔 배경의 자리표시 그림이 자동으로 만들어집니다

프로필 `.txt` 내용 (재학생):

```
이름: Gildong Hong
한글: 홍길동
직함:                    ← 비우면 접두사에 맞는 기본 직함이 자동 표시됨
이메일: hong@example.com
키워드: Soft robotics    ← 카드에 늘 보이는 한 줄

# 아래 4칸은 카드를 클릭하면 펼쳐지는 상세 패널. 전부 비우면 패널이 안 생깁니다.
소개: 한두 문장의 대표 연구 설명
논문:
- 논문 제목 하나 — <i>저널명</i>, 2026
- 또 하나
특허:
수상:
```

- `키: 값` 한 줄이 카드의 한 칸입니다. **비우면 그 칸은 표시되지 않습니다**
- `#`으로 시작하는 줄은 메모라서 화면에 안 나옵니다
- 논문·특허·수상은 바로 아랫줄부터 `- `로 시작하는 줄을 여러 개 적습니다
- 기울임(저널명 등)은 `<i>이렇게</i>` 감쌉니다

### 직책 태그 (랩장·부랩장·페이지 관리자)

`.txt` **맨 아래에 한 줄**만 추가하면 이름 옆에 배지가 붙습니다:

```
태그: 랩장
```

- 이름 **바로 위**에 영문 배지로 표시됩니다: `랩장`→`LAB LEADER`(파란 채움),
  `부랩장`→`VICE LEADER`(파란 테두리), `페이지 관리자`→`WEB ADMIN`(옅은 배지)
- 영문으로 직접 적으면 그대로 표시되고, 쉼표로 여러 개도 됩니다
- 직책이 바뀌면 이 줄만 다른 사람 파일로 옮기면 됩니다

### 1-3. 사진 넣기·바꾸기

- 파일 이름: 프로필과 **완전히 같은 이름** + `.png`/`.jpg` (예: `MS-001-JunwonJang.jpg`)
- 권장 크기: 정사각형 480×480 이상 (카드에서 동그랗게 잘려 나옵니다)
- **바꾸기**: 같은 이름으로 다시 올리면 덮어써집니다
- 자리표시 그림(파스텔 실루엣)이 이미 있는 사람에게 실제 사진 `.jpg`를 올리면 **사진이 우선** 표시됩니다

### 1-4. 졸업 처리하기

예: 학사과정 `BS-003-YeonwooChoi` 가 졸업할 때

1. `members/BS-003-YeonwooChoi.txt` 열기 → 연필 아이콘
2. 파일 이름 칸을 `ALU-006-YeonwooChoi.txt` 로 고치기 (**다음 졸업생 순번**으로)
3. 내용을 졸업생 형식으로 교체 → **Commit changes**

```
이름: Yeonwoo Choi
한글: 최연우
학위: B.S. (Electronics)
이메일: choiyeonwoo12@naver.com
현재: ○○회사 — 담당 업무      ← 비우면 표시 안 됨
```

4. 사진 파일도 이름을 맞춰 주세요: `BS-003-YeonwooChoi.png` 열기 → 연필 →
   이름을 `ALU-006-YeonwooChoi.png` 로… 는 이미지라 안 되니, **다운로드 후
   새 이름으로 업로드하고 옛 파일은 삭제**(파일 열기 → 오른쪽 위 `⋯` → Delete file)
   - 귀찮으면 옛 사진을 그냥 삭제만 해도 됩니다 (자리표시 그림이 자동 생성됨)
5. 빠진 순번(BS-003)은 그대로 두어도 괜찮습니다 — 순서만 결정할 뿐, 번호가 이어질 필요는 없습니다

### 1-5. 구성원 삭제·순서 바꾸기

- **삭제**: 그 사람의 `.txt`와 사진 파일을 Delete file
- **순서 변경**: 파일 이름의 순번을 바꾸면 됩니다 (같은 접두사 안에서 001이 맨 앞)

## 2. 갤러리 — `gallery/` 폴더

사진을 올리기만 하면 갤러리 페이지에 나타납니다. 최신 날짜가 위, 연도별로 묶여 표시되고,
사진을 누르면 크게 보기(←/→ 키로 넘기기, ESC로 닫기)가 열립니다.

### 파일 이름 규칙: `G-날짜-순번-제목`

```
G-2026_09_01-001-연구실OT.png     ← 사진 (.jpg 도 가능)
G-2026_09_01-001-연구실OT.txt     ← 제목·설명 (선택)
```

- 날짜는 `YYYY_MM_DD`, 순번은 `001`부터 — 같은 날짜 사진 여러 장의 표시 순서입니다
- 제목 부분은 한글도 됩니다. `.txt`를 안 올리면 파일 이름의 제목이 그대로 쓰입니다

`.txt` 내용:

```
제목: 2026년 연구실 OT
설명: 새 학기 오리엔테이션 단체 사진.
```

**삭제**는 파일을 지우면 되고, **설명만 고칠 때**는 `.txt`만 수정하면 됩니다.

## 3. 뉴스 — `data/news.txt`

News 페이지는 **연도별**로 묶여 표시됩니다. 연도 칸 하나는 이렇게 구성됩니다:

```
2025 ─────────────────────────────
[상장] [상장] [상장]        ← 수상 상장 가로 스트립 (awards/ 폴더, 3-6 참고)
── 소식 1 ──                ← 소식 목록 (data/news.txt)
── 소식 2 ──
```

### 3-1. 소식 한 건의 형식

`data/news.txt` 안에서 **`날짜:` 로 시작하는 한 묶음**이 소식 한 건입니다.

```
날짜: 2025
제목: Grand Prize at K-RISE Capstone X-Road 2025 (AI Modality)
내용: 김다완 교수팀이 K-RISE Capstone X-Road 2025 AI 모달리티 부문에서 최우수상을 수상했습니다.
본문: 누르면 펼쳐지는 전체 내용. 줄바꿈이 필요하면 <br> 을 씁니다.
링크: https://example.com/article
사진: images/news/2025-krise-capstone-xroad.jpg
```

| 칸 | 필수 | 화면에서 |
|---|---|---|
| `날짜` | ✅ | 앞 4자리(연도)로 묶음. 월은 표시되지 않으므로 `2025` 처럼 연도만 적어도 됩니다 |
| `제목` | ✅ | 굵은 제목 (사이트 톤에 맞춰 영문 권장) |
| `내용` | ✅ | 제목 아래 항상 보이는 한두 문장 요약 |
| `본문` | 선택 | 카드를 누르면 펼쳐지는 전체 내용 (줄바꿈은 `<br>`) |
| `링크` | 선택 | 제목 옆에 `LINK ↗` 배지가 붙고 클릭 시 새 탭으로 이동 |
| `사진` | 선택 | 왼쪽에 **132×92 썸네일**, 펼치면 원본 크기 |

선택 칸은 비워 두거나 줄 자체를 지워도 됩니다. `#`으로 시작하는 줄은 메모(화면에 안 나옴).

### 3-2. 새 소식 추가하기

1. 사진이 있으면 **`images/news/` 폴더에 먼저 업로드**합니다 (파일 이름은 자유, 영문·숫자 권장 — 예: `2026-03-workshop.jpg`)
2. `data/news.txt` 를 열어(연필 아이콘) **맨 아래에** 위 형식의 묶음을 붙여 넣고, `사진:` 에 `images/news/파일명` 을 적습니다
3. Commit → 1~2분 뒤 반영

### 3-3. 표시 순서 규칙

- 연도 칸은 **최신 연도가 위**입니다 (2025 → 2024 → 2023)
- 같은 연도 안에서는 **파일에서 아래에 있는 묶음이 위에 표시**됩니다. 시간순으로 맨 아래에 이어 붙이기만 하면 자동으로 최신이 위로 올라갑니다
- 순서를 바꾸고 싶으면 묶음 통째로 위치를 옮기면 됩니다 (연도가 다른 묶음끼리는 위치가 섞여 있어도 연도별로 알아서 묶입니다)

### 3-4. 카드가 동작하는 방식

| 소식에 있는 것 | 카드 모양 |
|---|---|
| 제목·내용만 | 제목 + 요약 (링크가 있으면 칸 아무 곳이나 눌러 이동) |
| 본문 또는 사진 있음 | `▾ CLICK FOR DETAILS` 표시 → 누르면 아래로 펼쳐져 **원본 사진 + 본문** (한 번에 하나만 열림). 링크는 `LINK ↗` 글자를 눌러야 이동 |

- 썸네일은 132×92 로 **가운데를 잘라** 보여 주므로 가로형 사진이 잘 어울립니다. 세로로 긴 포스터·표는 썸네일에서는 일부만 보이고 펼치면 전체가 보입니다
- 사진 파일 형식은 jpg / png / webp 모두 가능

### 3-5. 수정·삭제

- **글 수정**: 그 묶음의 해당 줄만 고칩니다
- **사진 교체**: `images/news/` 에 같은 이름으로 덮어쓰거나, 새 이름으로 올린 뒤 `사진:` 경로를 바꿉니다
- **소식 삭제**: `날짜:` 부터 `사진:` 까지 묶음을 통째로 지웁니다 (사진 파일도 함께 지우면 깔끔)

### 3-6. 수상 상장 — `awards/` 폴더

각 연도 칸 **맨 위에 같은 규격(150×200 흰 카드)으로 가로 나열**되는 상장입니다. 이름·내용을 따로 적지 않고 **파일만 올리면** 됩니다:

```
awards/A-2024-002-URP 포스터 경진대회 은상.png
       │  │    │    └ 상장 이름 → 사진 아래에 그대로 표시됩니다 (한글·공백 가능)
       │  │    └ 순번 → 그 연도 안에서 왼쪽부터의 순서
       │  └ 연도 → 어느 연도 칸에 들어갈지
       └ 상장 표시
```

- 상장 **전체가 보이도록** 카드 안에 맞춰지므로 세로형·가로형 어느 비율이든 됩니다. 누르면 원본이 새 탭으로 열립니다
- **이름 수정** = 파일 이름 변경 / **순서 변경** = 순번 변경 / **삭제** = 파일 삭제
- 파일 이름에 `/ \ ? #` 같은 기호는 쓰지 마세요 (공백·괄호·한글은 괜찮습니다)
- 상장만 있고 소식이 없는 연도도 연도 칸이 만들어집니다
- 상장이 많아지면 가로로 스크롤됩니다

### 3-7. 자주 하는 실수

- `제목:` 처럼 **칸 이름 뒤에 콜론**이 있어야 합니다 (전각 `：` 도 인식)
- `사진:` 경로에 오타가 있으면 썸네일 없이 글만 나옵니다 → 파일 이름과 대소문자를 확인
- 본문에서 엔터로 줄을 바꿔도 화면에서는 한 줄로 이어집니다 → 줄바꿈은 `<br>`
- 두 소식 사이에 `날짜:` 줄이 빠지면 앞 소식에 이어 붙어 버립니다

## 4. 특허 — `data/patents.txt`

뉴스와 같은 방식입니다. **새 특허는 파일 맨 아래에** 이어 붙이고 **번호를 하나 올려** 적으세요.
화면(Publications → Patents 탭)에는 번호가 큰 것부터, 연도별로 묶여 표시됩니다.

```
번호: 14
연도: 2026
제목: 특허 명칭
발명자: Da Wan Kim, 홍길동
등록번호: US12345678B2      ← 등록번호가 없으면 비워 두기
국가: US Patent             ← 예: Korea Patent / US Patent
뱃지: 기술이전               ← 선택 — 쉼표로 여러 개 가능, 없으면 줄을 지워도 됨
```

**뱃지**: `국가`가 US Patent 인 특허에는 **금색 `US PATENT` 뱃지가 자동**으로 붙습니다.
그 외에 강조하고 싶은 특허는 `뱃지:` 줄에 적으면 파란 뱃지로 표시됩니다 (예: `뱃지: 기술이전, 주요 특허`).

| 설정 | 용도 |

| `ifThreshold` | IF 배지가 붙는 기준값 (기본 10) |

## 6. 연구 분야 — `research/` 폴더

Research 페이지(왼쪽 사진 + 오른쪽 제목·요약의 세로 나열)와 홈 화면의 연구 카드가
**같은 파일**에서 나옵니다. 구성원·갤러리와 똑같이 파일만 올리면 됩니다.

### 파일 이름 규칙: `R-순번-영문이름`

```
R-001-SoftRobotElectronics.jpg     ← 왼쪽에 표시될 대표 사진 (.png 도 가능)
R-001-SoftRobotElectronics.txt     ← 제목과 요약
```

- **순번(001, 002…)이 곧 표시 순서**입니다 (위에서 아래로)
- 홈 화면 카드에는 **순번이 빠른 4개만** 표시되고, Research 페이지에는 전체가 표시됩니다
- `.txt` 내용:

  ```
  제목: Soft Robot & Electronics
  요약: 한두 문장의 연구 분야 소개.
  ```

- **내용만 고칠 때**: 해당 `.txt` 를 열어 수정
- **사진 교체**: 같은 이름으로 다시 업로드 (덮어쓰기)
- **분야 추가**: 다음 순번으로 두 파일 업로드 / **삭제**: 두 파일 삭제
- **순서 변경**: 파일 이름의 순번을 바꾸면 됩니다

## 사이트 검색 (자동)

상단 메뉴 오른쪽의 🔍 버튼(또는 `Ctrl+K`, `/`)으로 여는 검색창입니다. **따로 관리할 것이 없습니다.**

- 결과를 누르면 해당 페이지의 그 항목으로 이동해 잠시 강조하고, 펼침 카드는 자동으로 펼칩니다

## 13. 문제 해결

**고쳤는데 화면이 그대로예요**
- 1~2분 기다린 뒤 `Ctrl+F5` (Mac: `Cmd+Shift+R`)
- 그래도 안 되면 캐시 번호를 올립니다: 모든 `.html` 파일 안의 `?v=22` → `?v=23`,
  그리고 `js/common.js` 맨 위 `const ASSET_V = "?v=22"` → `"?v=23"`

**구성원/갤러리 파일을 올렸는데 안 나와요**
- 파일 이름이 규칙과 정확히 같은지 확인 (붙임표 `-` 위치, 순번 세 자리 `001`, 확장자 소문자)
- 올바른 폴더(`members/`, `research/`, `gallery/`, `awards/`) 안에 올렸는지 확인
- 저장소 **Actions 탭**을 열어 `update-manifest`가 초록색 ✓인지 확인.
  빨간 ✗이면 그 실행을 눌러 로그를 확인하고, 되면 **Re-run jobs**를 눌러 재실행
- Actions 탭에서 `update-manifest` → **Run workflow** 버튼으로 언제든 수동 실행할 수 있습니다

**한글이 깨져 보여요**
- 텍스트 파일을 컴퓨터에서 편집해 올린 경우, 저장할 때 인코딩을 **UTF-8**로 하세요
  (Windows 메모장: 다른 이름으로 저장 → 인코딩 UTF-8). GitHub 웹에서 편집하면 문제 없습니다

**형식이 꼬여서 페이지가 이상해요**
- 그 파일 → **History** → 이전 버전 열기 → 내용 복사해서 되돌리기

**사이트가 아예 안 떠요**
- 저장소 이름이 `KNUT-SERL.github.io` 그대로인지, 루트에 `index.html`이 있는지 확인
- 저장소 Settings → Pages 에서 Source가 `main` 브랜치인지 확인

## (참고) 사이트가 자동으로 돌아가는 원리

`members/`·`research/`·`gallery/`·`awards/`에 파일이 올라오면 GitHub Actions(`update-manifest`)가 폴더를 훑어
사이트가 읽는 목록(`data/manifest.json`)을 자동으로 갱신하고, 사진 없는 구성원에게
자리표시 그림을 만들어 줍니다. 이 과정은 자동이므로 **`data/manifest.json`과
`tools/`, `js/`, `.github/` 안의 파일은 직접 고칠 필요가 없습니다.**
